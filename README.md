# QuestSpoofer - Discord QuestSpoofer

Discord QuestSpoofer script to complete quests and claim rewards using DOM video acceleration and API timestamp spoofing for video tasks, `RunningGameStore` process ID/executable hooking for desktop games, `ApplicationStreamingStore` metadata injection for streams, and `FluxDispatcher` heartbeat events for activities.

<p><font color="red">⚠️ CAUTION: Paste code into the console at your own risk. Only use scripts from trusted sources to avoid account compromise.</font></p>

## How to Run

1. Open Discord.
2. Press `Ctrl + Shift + I` to open DevTools.
3. Type `allow pasting` in the console and press Enter.
4. Paste the loader script:

```javascript
fetch('[https://raw.githubusercontent.com/efnking69/DiscordQuestSpoofer/main/script.js').then(r=](https://raw.githubusercontent.com/efnking69/DiscordQuestSpoofer/main/script.js').then(r=)>r.text()).then(eval);

```

5. Press `INSERT` to open the menu.

## Features

* Auto completes video, desktop games, streams, and activities
* Auto enrolls in quests
* Auto claims rewards
* Built-in UI and desktop notifications

### Supported tasks:

* `WATCH_VIDEO` = Can watch videos automatically.
* `PLAY_ON_DESKTOP` = Can spoof playing desktop games.
* `STREAM_ON_DESKTOP` = Can spoof streaming on desktop.
* `PLAY_ACTIVITY` = Can spoof playing activities in voice channels.
* `WATCH_VIDEO_ON_MOBILE` = Can watch videos even the ones meant for mobile.
